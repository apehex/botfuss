# Roadmap

Incremental plan for the project.

---

## Phase 0 - Setup

- define repository structure
- write core documentation
- define initial asset format

---

## Phase 1 - World Extraction

- extract data from Kingkiller sources
- populate:
  - characters
  - locations
  - events

Goal:
- build a usable world database

---

## Phase 2 - Basic Consistency

- ensure assets are readable and coherent
- resolve obvious conflicts
- refine structure

---

## Phase 3 - First Simulation

- define a minimal "engine":
  - pick time + location
  - select relevant assets
  - simulate simple interactions

- record logs

---

## Phase 4 - Narrative Extraction

- select interesting events from logs
- build simple story outlines
- generate basic prose

---

## Phase 5 - Iteration

- refine schemas
- improve agent behavior
- expand world
- experiment with branches

---

## Open Questions

- how to represent time consistently?
- how to handle conflicting variants?
- how to evaluate "interesting" events?
- how to maintain coherence across simulations?
