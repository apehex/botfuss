# Invariants

Hard constraints that should not be violated.

---

## Structure

- assets must remain human-readable
- files must stay reasonably small and focused
- directory structure must remain stable

---

## Philosophy

- prioritize clarity over cleverness
- avoid hidden logic in file names alone
- avoid implicit conventions without documentation

---

## Data Integrity

- no silent overwrites of important information
- conflicting versions must coexist, not replace each other
- deletions should be explicit and justified

---

## Collaboration

- contributions should be incremental
- no large unreviewed changes
- document structural decisions

---

## Evolution

- do not prematurely optimize
- prefer simple systems that can evolve
- avoid locking into rigid schemas too early
